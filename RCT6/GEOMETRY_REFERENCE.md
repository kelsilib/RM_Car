## 2. 四轮中心与坐标含义

原CAD坐标为X横向、Y竖向、Z两排轮子排列方向。用户已确认凹口为车头；底盘缓存网格的中央部分在-Z端缩进约40mm，支持凹口对应-Z。因此车体前进为CAD的-Z、向左为CAD的-X、向上为CAD的+Y。以下保留原A/B/C/D代号，并补齐空间名称；它们还不是实际M1～M4接线的验收结果。

| 轮子 | 当前空间名称 | CAD X / mm | CAD Y / mm | CAD Z / mm |
|---|---|---:|---:|---:|
| A：+Z排、+X侧 | 右后 RR | +97.050778 | 24.006596 | +82.439400 |
| B：+Z排、-X侧 | 左后 RL | -97.050778 | 24.006596 | +82.439400 |
| C：-Z排、+X侧 | 右前 FR | +97.050778 | 24.006596 | -59.336779 |
| D：-Z排、-X侧 | 左前 FL | -97.050778 | 24.006596 | -59.336779 |

四轮矩形中心约为CAD `(0, 24.006596, 11.551310)` mm。当前运动学以这个矩形中心为默认旋转中心，不能把CAD原点自动当成旋转中心。

以四轮矩形中心为原点，代码机体系坐标为：左前`(+a,+b)`、右前`(+a,-b)`、左后`(-a,+b)`、右后`(-a,-b)`，其中`a=0.070888089544m`、`b=0.097050777636m`。代码数组顺序为FL/FR/RL/RR，即D/C/B/A。当前候选驱动通道仍为M1/M3/M2/M4，所有`direction`保持0，等架空逐轮核对后再填正负号。

## 3. 为什么能把轮子原点当作此模型的轮心

本次不仅取了子装配原点，还读取了`80-3d.stp`对应的独立网格记录：2365个面表、151544个含重复的顶点，并按记录声明的面数限制读取边界，避免混入电机和支架。

轮子中心孔的24个不同XY采样点拟合出约2mm半径的圆，圆心约为局部`(0,0)`，最大拟合残差约`8.72e-11m`；轮子的局部轴向包络为`[-18.7,+18.7]mm`。结合轮子在轮电机子装配中的恒等变换，这些证据支持本模型的轮心使用局部`(0,0,0)`。这是缓存网格的数值自洽检查，不是精密计量精度承诺，也不能代替实物轴孔/轮径测量。

## 4. CAD与实物麦轮的区别

**原CAD中四个轮子都引用同一份`80-3d.stp`模型；同侧前后实例的旋转矩阵相同，没有镜像。** 这份缓存模型不能证明实物60mm麦轮的左右旋和安装方式。用户后来提供的实物照片已显示两种轮子对角配对，当前摆放符合X布局；之前仅凭CAD留下的布局疑点，不应继续写成实车装错。

现有`src/mecanum.c`按标准X布局计算：前进同号、左移`[-,+,+,-]`、逆时针`[-,+,-,+]`。WPILib官方说明和REV厂商安装说明均要求相应布局从上方看滚子轴线组成X，通常使用两只左旋和两只右旋轮、相同类型在对角位置。资料来源：

- [WPILib：Mecanum wheel arrangement](https://docs.wpilib.org/en/stable/docs/software/hardware-apis/motors/wpi-drive-classes.html)
- [REV：Mecanum Wheel Setup and Behavior](https://docs.revrobotics.com/duo-build/mecanum-drivetrain-v2/mecanum-wheel-setup-and-behavior)

后续装车时保持照片中的对角配对关系，再从上方核对滚子布局。照片只能提供摆放依据，不能代替装配后的检查；也不能靠只改电机`direction`正负号来证明滚子几何正确。

## 5. 对代码参数的影响

当前代码已填入以下参数：

```c
/* 轮径按用户确认的60mm；两项轮心距暂按CAD，装好实物后复核。 */
.radius_m      = 0.030f,
.half_length_m = 0.070888089544f,
.half_width_m  = 0.097050777636f,
.geometry_verified = false,
```

轮半径按`60/2000=0.030m`换算；半轴距和半轮距分别是前后、左右轮心距除以2000。60mm是用户确认的名义轮径，有效滚动直径以后还可通过滚动距离标定。不能把CAD最大网格包络80.142745mm当成当前实物轮径，也不能把模型轮宽37.4mm当成实物轮宽。轮径还会影响智能驱动板的`wdiameter`配置，需要核对厂商参数单位；本次没有向驱动写入参数。

填入尺寸只让运动学能按现有依据计算，不等于允许行驶。未设置任何生产`*_verified=true`，未启用PS2、标定或运动。实物轮心距、速度命令单位、轮序、电机方向、无线失联和驱动独立停车仍按[待核实配置](CONFIG_PENDING.md)逐项完成。
